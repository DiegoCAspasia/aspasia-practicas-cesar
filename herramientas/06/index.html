Introduce la dirección completa de la página. Se utilizará para clasificar los enlaces internos y externos.

Nota sobre el análisis: esta herramienta analiza el código HTML que se le proporciona. Los contenidos que se generan dinámicamente mediante JavaScript y que no estén presentes en ese código fuente podrían no aparecer en los resultados. Tampoco comprueba directamente las respuestas HTTP, la indexación real en Google ni la reciprocidad de las etiquetas canonical y hreflang.
